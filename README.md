# 蓝桥杯 2027 刷题目录

环境已经配好了，**不需要再装任何东西**。有三条路可以跑代码，选最顺的一条。

## 路线 A：最稳，双击就能跑（推荐先用这个）

1. 打开 `w01_syntax` 文件夹
2. 双击 `hello.cpp`（会用它默认关联的编辑器打开）
3. 改完保存，**把 `.cpp` 文件拖到本目录的 `run.bat` 图标上**，松手

会弹出一个黑窗口，自动编译并运行。要输入数据就直接在窗口里敲。

也可以在终端里指定文件跑：

```
run.bat w01_syntax\hello.cpp
```

## 路线 B：VS Code（配置已就绪）

用 VS Code 打开 `lanqiao2027` 文件夹，改完代码按：

- **F5** —— 编译 + 运行，输出在下方终端里，可以直接敲输入
- **Ctrl+Shift+B** —— 只编译不检查运行，用来挑语法错误

> 注：这套配置（`.vscode/tasks.json`、`launch.json`、`settings.json`）已经写好并校验过，VS Code 一打开就能用。如果 VS Code 打不开，走路线 A。

## 路线 C：命令行

编译器的目录已经加进用户 PATH，**新开**一个终端后可以直接用：

```
g++ -std=c++17 -O2 hello.cpp -o hello.exe
hello.exe
```

（已经在运行的终端窗口读不到新的 PATH，重开一个就好。）

## 先跑一次自检

任选一条路线运行 `w01_syntax/hello.cpp`，输入：

```
3 5
```

回车。看到 `ok 8`，说明 编译 / 运行 / 键盘输入 三件事全部正常。

## 目录约定

| 目录 | 放什么 |
|---|---|
| `w01_syntax` | 语法与 STL 练习（11/20 — 12/31） |
| `w02_algorithm` | 基础算法：枚举、二分、前缀和、DFS/BFS、贪心（1/1 — 2/28） |
| `w03_dp_graph` | 提高：DP、并查集、最短路、数论（3/1 — 3/31） |
| `w04_past` | 历年省赛真题，按年份建子文件夹，套卷限时做 |

## 命名约定

一道题一个文件，用题号命名，方便以后回头查：

```
w02_algorithm/P2249.cpp      洛谷题号
w04_past/2019B_T1.cpp        年份 + 组别 + 题号
```

> 两条注意：
> 1. 文件夹和文件名请保持英文。中文路径在部分场合会让编译器找不到输出文件，出问题时很难排查。
> 2. 机器上还装了小熊猫C++（自带 g++ 11.4.0），但它的命令行调用在实测中会静默失败，先别用。
